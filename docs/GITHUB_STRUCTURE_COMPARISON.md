# Repository Structure Comparison with Top-Starred GitHub Windows Utilities

To ensure **WinBreathe** follows the gold-standard repository layout of the highest-starred Windows optimization projects on GitHub—specifically [**`ChrisTitusTech/winutil`**](https://github.com/ChrisTitusTech/winutil) (~30,000+ ★) and [**`hellzerg/optimizer`**](https://github.com/hellzerg/optimizer) (~16,000+ ★)—while keeping WinBreathe's unique hardware-adaptive RAM/HDD & AI-stack engineering, the repository implements the exact structural conventions below:

| Structural Pillar | `ChrisTitusTech/winutil` (30k+ ★) / `hellzerg/optimizer` (16k+ ★) | `WinBreathe` Implementation |
| :--- | :--- | :--- |
| **Single-File Native Executable (`.exe`)** | `Optimizer.exe` — Self-contained C#/.NET executable with custom icon, UAC `requireAdministrator` manifest, and `PerMonitorV2` DPI awareness | [`WinBreathe.exe`](../WinBreathe.exe) + [`src/Launcher/Program.cs`](../src/Launcher/Program.cs) + [`app.manifest`](../src/Launcher/app.manifest) compiled via native `.NET Framework x64 csc.exe` with embedded resources |
| **Root Build / Bundler Pipeline** | `Compile.ps1` — Validates syntax, bundles configs/scripts, and outputs distributable artifacts | [`Compile.ps1`](../Compile.ps1) — Validates PowerShell AST & pure ASCII, embeds engine/GUI/JSON/assets into `WinBreathe-v1.1.0-x64.exe` & `WinBreathe-v2.0.0-x64.exe`, builds `.zip` bundles, and generates `SHA256SUMS.txt` |
| **Declarative JSON Tweak Catalog** | `config/tweaks.json`, `config/feature.json` — All registry, service, and policy definitions externalized from code | [`config/tweaks.json`](../config/tweaks.json) — 24 declarative tweaks with `Conservative`, `Balanced`, and `Aggressive` profile rules and `protectedProcesses` safety lists |
| **Modular Engine & Entrypoints** | `functions/` & `scripts/` separation | [`src/WinBreathe.Engine.psm1`](../src/WinBreathe.Engine.psm1), [`src/WinBreathe.ps1`](../src/WinBreathe.ps1), [`src/WinBreathe.GUI.ps1`](../src/WinBreathe.GUI.ps1), and legacy [`src/v1/`](../src/v1/) |
| **Versioned Release Binaries & Checksums** | Pre-built `.exe` + Portable `.zip` + `SHA256` hashes per release tag (`v1.x`, `v2.x`) | [`releases/v1.1.0/`](../releases/v1.1.0/) and [`releases/v2.0.0/`](../releases/v2.0.0/) containing standalone `.exe`, `.zip`, and `SHA256SUMS.txt` |
| **GitHub Community & CI/CD Standards** | `.github/workflows/`, `.github/ISSUE_TEMPLATE/*.yml`, `PULL_REQUEST_TEMPLATE.md`, `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md` | Full `.github` automation ([`lint.yml`](../.github/workflows/lint.yml), [`build-release.yml`](../.github/workflows/build-release.yml)), YAML issue forms, PR checklist, and security policy |
